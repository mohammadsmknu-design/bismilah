# WiFi Analyzer Pro 📶

Aplikasi analisis jaringan sederhana yang dibangun menggunakan Flutter untuk memenuhi tugas UAS Pengembangan Aplikasi Mobile.

## Fitur Utama
- **Real-time SSID Detection:** Menampilkan nama WiFi yang sedang terhubung.
- **Modern UI:** Menggunakan tema Dark Mode yang elegan dan minimalis.
- **Refresh Capability:** Memperbarui data jaringan secara instan.

## Cara Penggunaan
1. Pastikan GPS/Lokasi pada perangkat sudah aktif.
2. Berikan izin lokasi saat aplikasi pertama kali dijalankan.
3. Klik tombol 'Refresh' untuk memperbarui nama SSID.

## Spesifikasi Teknis
- Flutter SDK: ^3.11.1
- Library: `network_info_plus`, `connectivity_plus`
